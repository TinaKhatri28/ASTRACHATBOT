# ASTRABOT
A domain-specific AI chatbot for agriculture, providing intelligent responses on crops, soil health, pests, and sustainable farming using NLP and ML.

# AGRICULTURAL BASED ASSISTANT BOT

# HOW TO RUN:
### STEPS:
Clone the repository
```bash
Project repo: https://github.com/dashboard
```
### STEP01- Create a conda environment after opening the repo

```bash
conda create -n agribot python=3.8 -y
```

```bash
conda activate agribot
```
### STEP 02 - install requirements
```bash
pip install -r requirements.txt
```
